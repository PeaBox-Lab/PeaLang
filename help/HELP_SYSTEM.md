# Built-in Help System

## From Windows CMD or PowerShell

```cmd
pea help
pea help topics
pea help getting-started
pea help repl
pea help syntax
pea help functions
pea help debugging
```

## From the PeaLang REPL

```text
pea> help
pea> help functions
pea> :help repl
pea> ? syntax
pea> :examples
```

Available topics: `getting-started`, `repl`, `syntax`, `variables`, `functions`, `collections`, `files`, `errors`, `debugging`, and `commands`.
