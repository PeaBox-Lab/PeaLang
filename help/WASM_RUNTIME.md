# True standalone WASM bytecode VM (v1.3.0)

PeaLang provides enhanced WASM compilation and browser runtime support.

## Key functions

- `analysis.capability_bridge_source(capabilities)` — browser capability bridges
- `analysis.web_worker_runtime_source()` — Web Worker runtime
- `analysis.capability_sandbox_policy(capabilities)` — sandbox policy
- `analysis.wasm_module_manifest(name, exports, imports, capabilities)` — module manifest
