# Developer experience (v137)

PeaLang provides developer experience and tooling enhancements.

## Key functions

- `analysis.suggest_fix(error_msg)` — suggest fixes
- `analysis.explain_error_detailed(error, source, line)` — detailed explanation
- `analysis.project_scaffold(name, template, target_dir)` — scaffold project
- `analysis.code_metrics(source)` — code metrics
- `analysis.lint_source(source)` — linting
- `analysis.format_source(source)` — formatting
- `analysis.dependency_check(manifest_path)` — dependency check
