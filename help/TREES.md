# Decision trees and random forests help

Use `stats` (or `std.stats`) for trees; everything is dependency-free and returns ordinary records. Trees: `decision_tree(features, target, task, max_depth, min_samples_split, min_samples_leaf, max_features, seed)` with `task` set to `"regression"` or `"classification"`. Predict: `predict_tree(model, features)` returns `predicted` and, for classification, `probabilities` and `classes`. Importance: `tree_feature_importance(model, names)`. Forests: `random_forest(features, target, task, n_estimators, max_depth, min_samples_split, min_samples_leaf, max_features, bootstrap, seed)`, `predict_forest`, `forest_feature_importance`. `max_features` accepts an int, a fraction, `"sqrt"`, `"log2"`, `"all"` or `null`. `max_depth = null` is capped at 100. With `bootstrap = true`, forests report `oob_score` and `oob_predictions`. Record wrappers: `analysis.tree_report(data, target, features, task, max_depth, min_samples_split, min_samples_leaf)` and `analysis.forest_report(data, target, features, task, n_estimators, max_depth, min_samples_split, min_samples_leaf, max_features, bootstrap, seed)`, where `task = "auto"` infers classification for boolean or 0/1 targets. See `docs/TREE_MODELS.md`.
