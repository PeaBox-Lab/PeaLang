# Model evaluation help

Use `stats` (or `std.stats`) for evaluation; everything is dependency-free and returns ordinary records. Splits: `train_test_split(features, target, test_size, shuffle, seed, stratify)`. Folds: `k_fold(samples, k, shuffle, seed)` and `stratified_k_fold(labels, k, shuffle, seed)`. Classification: `accuracy_score`, `balanced_accuracy`, `precision_recall_fscore(actual, predicted, positive)`. Ranking and probability: `roc_auc`, `roc_curve`, `log_loss`, `brier_score`, `calibration_curve(actual, probabilities, bins, positive)`. Regression: `mean_squared_error`, `root_mean_squared_error`, `mean_absolute_error`, `median_absolute_error`, `mean_absolute_percentage_error`, `r2_score`, `explained_variance_score`. Features: `polynomial_features(features, degree, include_bias, interaction_only, names)`, `label_encode`, `ordinal_encode`, `standardize_features`, `standardize_transform`, `minmax_features`, `minmax_transform`. Record wrappers: `analysis.train_test_split`, `analysis.evaluate_classification`, `analysis.evaluate_regression`, `analysis.add_polynomial_features`. See `docs/MODEL_EVALUATION.md`.
