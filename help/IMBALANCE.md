# Class imbalance help

Use `stats` (or `std.stats`) to rebalance classification data; everything is dependency-free and returns ordinary records. Report: `class_balance(target)` returns `n`, sorted `classes`, a `counts` table of `{class, count, share}`, `majority`, `minority` and `imbalance_ratio` (largest count divided by smallest). Resamplers all take `(features, target, seed)` and return `{method, features, target, n, added, removed, seed}`: `random_oversample` duplicates random minority rows with replacement until every class matches the majority; `random_undersample` drops random majority rows without replacement until every class matches the minority; `smote(features, target, k, seed)` synthesizes minority rows by interpolating between a base row and one of its `k` nearest same-class neighbors. SMOTE caps `k` at `count - 1`, duplicates a single-row class, and balances multiclass targets class by class. Record wrapper: `analysis.balance_classes(data, target, features, method, k, seed)` accepts `"smote"`, `"oversample"`/`"over"`/`"random_oversample"` or `"undersample"`/`"under"`/`"random_undersample"`, and returns `rows`, `method`, `features`, `n_used`, `n`, `added`, `removed`, `before`, `after`, `imbalance_ratio_before`, `imbalance_ratio_after` and `seed`. Pass `result["rows"]` to `analysis.forest_report` and friends. Resample the training data only and score on the untouched test set. Encode categorical predictors numerically before SMOTE. See `docs/CLASS_IMBALANCE.md`.
