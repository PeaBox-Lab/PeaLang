# Causal inference help

Use `stats` (or `std.stats`) for causal effects; everything is dependency-free and returns ordinary records. Propensity scores: `propensity_scores(features, treatment, names, confidence)`. Balance: `covariate_balance(features, treatment, names, weights)` with `smd` and, when weights are supplied, `weighted_smd`. Weighting: `ipw_ate(features, treatment, outcome, trim, confidence, samples, seed)` and `aipw_ate(...)` for the doubly robust estimator. Matching: `propensity_match(features, treatment, outcome, caliper, ratio, replace, confidence)`. Difference-in-differences: `difference_in_differences(outcome, treated, post, covariates, names, cluster, confidence)`. Instrumental variables: `instrumental_variables(instruments, endogenous, outcome, controls, names, instrument_names, confidence)`. Regression discontinuity: `regression_discontinuity(running, outcome, cutoff, bandwidth, degree, confidence)`. Record wrappers: `analysis.causal_report`, `analysis.did_report`, `analysis.iv_report`, `analysis.rdd_report`. See `docs/CAUSAL_INFERENCE.md`.
