# Numerics help

Use `stats` (or `std.stats`) for dependency-free numerical work. Descriptive statistics: `mean`, `median`, `mode`, `quantile`, `percentile`, `iqr`, `variance`, `std`, `skew`, `kurtosis`, `covariance`, `pearson`/`correlation`, `spearman`, `kendall`, `entropy`, `gini`, `describe`. Transforms: `zscore`, `minmax_scale`, `robust_scale`, `winsorize`, `cumsum`, `cumprod`, `cummax`, `cummin`, `diff`, `histogram`, `outliers_z`, `percentile_rank`. Linear algebra: `dot`, `norm`, `distance`, `angle`, `add`, `sub`, `mul`, `div`, `scale`, `outer`, `transpose`, `identity`, `matmul`, `trace`, `solve`, `determinant`, `inverse`. Distributions: `normal_pdf`/`cdf`/`ppf`/`interval`, `uniform_pdf`/`cdf`, `exponential_pdf`/`cdf`, `binomial_pmf`/`cdf`, `poisson_pmf`/`cdf`, `t_pdf`/`t_cdf`, `f_cdf`, `chi2_cdf`. Tests: `t_test_1samp`, `t_test_ind`, `welch_t_test`, `t_test_paired`, `chi_square_test`, `anova_oneway`. Modelling: `linear_regression`, `multiple_regression`, `polyfit`, `polyval`, `r_squared`, `interpolate`, `linspace`, `arange`, `kmeans`, `pca`, `confusion_matrix`. Sampling: `random_uniform`, `random_normal`, `random_binomial`, `random_poisson`, `bootstrap`. For tabular pandas-class helpers (`qcut`, rolling/expanding variants, `pivot_table`, `factorize`, `info`, `missing_summary`, and more) use `analysis`. See `docs/DATA_SCIENCE.md`.
