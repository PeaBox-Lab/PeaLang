# Inference help

Use `stats` (or `std.stats`) for statistical inference and time-series analysis; everything is dependency-free and returns ordinary records. Estimation: `standard_error`, `confidence_interval_mean`, `confidence_interval_proportion` (Wilson), `confidence_interval_diff_means` (Welch), `margin_of_error`, `bootstrap_ci`. Effect size and power: `cohens_d`, `hedges_g`, `eta_squared`, `power_t_test`, `sample_size_t_test`. Multiple comparisons: `adjust_p_values` / `multiple_comparison` with `"bonferroni"`, `"holm"`, or `"bh"`. Parametric tests: `z_test_1samp`, `proportion_test`, `z_test_proportions`, `fisher_exact`, `chi_square_goodness_of_fit`. Nonparametric tests: `mann_whitney_u`, `wilcoxon_signed_rank`, `kruskal_wallis`, `friedman_test`, `sign_test`. Normality and resampling: `jarque_bera`, `normality_test`, `permutation_test`. Regression: `ols` (coefficient table, standard errors, t/p values, confidence intervals, R², adjusted R², F-test, AIC/BIC, Durbin-Watson, covariance), `predict_ols` (prediction intervals), `variance_inflation_factors`, `residual_diagnostics`. Time series: `acf`, `pacf`, `ljung_box`, `difference_series`, `moving_average`, `simple_exponential_smoothing`, `holt_linear`, `holt_winters`, `seasonal_decompose`, `changepoint_cusum`, `adf_test`. Inverse distributions: `t_ppf`, `chi2_ppf`, `f_ppf`. Record-friendly wrappers: `analysis.regression_report` and `analysis.time_series_report`. See `docs/STATISTICAL_INFERENCE.md`.
