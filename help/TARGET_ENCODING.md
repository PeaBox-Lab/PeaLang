# Target encoding help

Use `stats` (or `std.stats`) to encode categorical columns by the smoothed mean of a numeric target, without dependencies. `stats.target_encode(values, target, smoothing, min_count)` returns `{method, smoothing, min_count, prior, kind, classes, levels, n}` where `levels` holds `{level, count, mean, encoded}` records in sorted order. `stats.target_apply(encoder, values)` returns floats; unseen categories and missing values use the fitted `prior`. The default smoothing is `10.0` and the default `min_count` is `1`; the encoded value is `(count * mean + smoothing * prior) / (count + smoothing)`, and a level seen fewer than `min_count` times uses the prior. Numeric targets are used as-is; two-class targets are mapped to `0`/`1` in sorted class order and the encoded value is the smoothed share of the second class, reported in `classes`; more than two non-numeric classes raise. Targets must be complete. In a pipeline, `{"op": "target", "columns": [...], "smoothing": 10.0, "min_count": 1, "required": true}` (alias `target_encode`) encodes the named columns, or all non-numeric columns when `columns` is omitted; `required: false` makes it a no-op when nothing is categorical. Pass the target as the fourth argument to `stats.fit_pipeline(steps, features, names, target)`; `analysis.model_pipeline` passes its training outcomes automatically. Order steps impute, target, encode, scale. Target encoding leaks target information on training rows, so fit on training data and apply to held-out rows, and cross-fit inside folds. Fitted steps persist through `stats.save_model` / `stats.load_model`. See `docs/TARGET_ENCODING.md`.
