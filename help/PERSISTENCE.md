# Model persistence help

Fitted `stats` models and pipeline transformers are plain records, so they save as versioned JSON without pickle. Use `stats.save_model(path, model, indent, compact)` to write one and `stats.load_model(path)` to read it back; `indent = 0` writes minified JSON and parent directories are created. The document is `{format: "pealang.model", version: 1, kind, payload}` where `kind` is `"model"` or `"pipeline"` and `payload` is the fitted record. `stats.export_model(model, compact)` returns that document without touching the filesystem and `stats.import_model(document)` validates one from memory. `compact = true` drops `train_predictions` and `oob_predictions` but keeps everything needed for scoring. `stats.model_summary(model)` returns `{kind, estimator, task, features, output_features, n_features, classes, n, metrics, top_features, has_preprocessor}` for a model, or `{kind: "pipeline", steps, input_names, names, n_features, n}` for a transformer. Metrics are a subset of `train_accuracy`, `train_log_loss`, `train_r2`, `train_rmse` and `oob_score`. Export rejects non-records, records not produced by a stats estimator or pipeline, non-finite numbers, non-string keys and non-JSON objects; import rejects wrong formats, versions, kinds and missing payloads. Reloaded models score identically, including their fitted preprocessor. See `docs/MODEL_PERSISTENCE.md`.
