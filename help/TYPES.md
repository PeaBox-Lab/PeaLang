# Type help

Use optional annotations, generics such as `function first<T>(items: List<T>) -> T?`, protocol bounds such as `function show<T: Printable>(value: T)`, marker traits such as `trait Serializable`, and `Result<T,E>`, `Option<T>`, `Future<T>`, `Iterable<T>`, `Iterator<T>`. Static analysis scopes type parameters, infers type arguments at call sites, checks bounds, compares nested generic arguments, verifies structural protocol signatures with `P201`–`P205`, reports `I201` for known non-iterable `for` targets, and models `async function` declarations as `Future<T>` with `A201` diagnostics for awaiting known non-futures. Conformance is checked only for protocols or traits used in generic bounds. Runtime annotations, protocols, traits, and async annotations remain erased.
