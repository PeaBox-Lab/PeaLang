# Gradient boosting help

Use `stats` (or `std.stats`) for boosted trees; everything is dependency-free and returns ordinary records. Fit: `gradient_boosting(features, target, task, n_estimators, learning_rate, max_depth, min_samples_split, min_samples_leaf, subsample, max_features, seed)` with `task` set to `"regression"` or `"classification"`. Regression uses squared error; two classes use logistic loss; more than two classes use softmax with one tree per class per round. Predict: `predict_boosting(model, features)` returns `predicted` and, for classification, `probabilities` and `classes`. Importance: `boosting_feature_importance(model, names)`. `subsample` below 1 enables stochastic boosting. `max_features` accepts an int, a fraction, `"sqrt"`, `"log2"`, `"all"` or `null`. `max_depth = null` is capped at 100; boosting normally uses depth 2-4. Record wrapper: `analysis.boosting_report(data, target, features, task, n_estimators, learning_rate, max_depth, min_samples_split, min_samples_leaf, subsample, max_features, seed)`, where `task = "auto"` infers classification for boolean, non-numeric, and low-cardinality integer targets. See `docs/GRADIENT_BOOSTING.md`.
