# CLI Help

Run `pea --version`, `pea run FILE`, `pea repl`, `pea fmt PATH`, `pea check PATH`, `pea test`, `pea docs FILE`, `pea init PATH`, `pea project`, `pea start`, `pea add NAME PATH`, or `pea remove NAME`.

## Package integrity

`pea lock [PROJECT]` creates or refreshes `pea.lock`. `pea verify [PROJECT]` validates locked dependency hashes and exits non-zero on mismatch.
