# Interactive Web Data IDE (v1.8.0)

PeaLang provides a self-hosted Web Data IDE with reactive cell execution.

## Key functions

- `analysis.ReactiveCell(id, source, deps)` — reactive cell
- `analysis.ReactiveNotebook()` — reactive notebook
- `analysis.inspect_dataframe(data)` — DataFrame inspector
- `analysis.inspect_sql_result(query, result)` — SQL result inspector
- `analysis.publish_as_webapp(source, title, template)` — publish as web app
- `analysis.generate_notebook_html(cells)` — notebook HTML
