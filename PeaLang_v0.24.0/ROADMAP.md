# Roadmap

- **0.24:** semantic flow analysis and contract diagnostics, delivered.
- **0.25:** FastAPI integration package, dependency injection, Pydantic conversion, validation middleware, and OpenAPI extension schemas.
- **0.26:** async functions, await, cancellation, task groups, async host calls, and FastAPI-native async execution.
- **0.27:** package resolver, `pea.toml`, lock files, checksums, signatures, and private feeds.
- **0.28:** Java runtime sidecar, Java SDK, and Spring Boot starter.
- **0.29:** TypeScript SDK, React hooks, UI schema renderer, and WebAssembly experiment.
- **1.0:** stable specification, PEAC compatibility policy, embedding ABI, package format, and security review.
