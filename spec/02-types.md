

# Types

Core type names are `Any`, `Never`, `Null`, `Bool`, `Int`, `Float`, `Number`, `String`, `List<T>`, `Map<K,V>`, `Set<T>`, `Tuple<T...>`, `Result<T,E>`, `Option<T>`, `Future<T>`, and `Function`. Type annotations are optional. `T?` denotes nullable `T`; `A | B` denotes a union. Records are structural data declarations. Generic and protocol semantics remain Preview until their complete static semantics are specified.
