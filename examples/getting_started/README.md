# Getting started with PeaLang (ready-made examples)

These are complete, ready-to-run examples generated by the PeaLang frameworks
toolkit. Copy any of them and run it — no setup beyond the listed commands.

Run each example's test-suite **from inside its own directory** (the examples
use the same test module name, so collecting both at once fails):

```bash
cd examples/getting_started/fastapi_orders && pytest     # OK
cd examples/getting_started/fullstack_shop/backend && pytest   # OK
# `pytest examples/getting_started/fastapi_orders examples/getting_started/fullstack_shop/backend` together does NOT work
```

## 1. `fastapi_orders/` — FastAPI backend service

Pattern-matched copy of `pea scaffold fastapi examples/getting_started/fastapi_orders` output.

```bash
cd examples/getting_started/fastapi_orders
python -m venv .venv && . .venv/Scripts/activate   # or .venv/bin/activate on Linux/macOS
pip install -r requirements.txt
pytest                                              # runs the health check test
uvicorn app.main:app --reload                       # serves on :8000
```

Endpoints:
- `GET /health` → `{"status": "ok", "service": "orders"}`


## 2. `fullstack_shop/` — FastAPI backend + React frontend

```bash
cd examples/getting_started/fullstack_shop/backend
pip install -r requirements.txt
uvicorn app.main:app --reload        # backend on :8000 from the scaffold default; edit to change
cd ../frontend
npm install && npm run dev           # Vite dev server
```

The React app polls the backend `/health` endpoint on mount.

## 3. More frameworks (available since v2.14/2.15)

```bash
pea scaffold flask ./mysvc
pea scaffold express ./mysvc
pea scaffold gin ./mygateway
pea scaffold django ./mysvc        # Django, needs Python runtime
pea scaffold fullstack ./shop      # backend + frontend in one directory
# fullstack frontend options:
#   --frontend react   (default)
#   --frontend nextjs
```

## 4. Requirement notes

- These backend examples need Python 3.10+ and network access to `pip install`.
- The React frontend needs Node 18+ and `npm`.
- If `uvicorn` is blocked in your environment, run the FastAPI test-suite only (`pytest`).

## 5. Where the generated code came from

```bash
pea scaffold fastapi <dir>    # same as fastapi_orders/
pea scaffold fullstack <dir>  # same as fullstack_shop/
```
