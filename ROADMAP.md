# Roadmap

- **0.18:** Python embedding, delivered.
- **0.19:** optional type contracts, delivered.
- **0.20:** bytecode compiler and VM, delivered.
- **0.21:** VM parity, debugging state, and VM embedding, delivered.
- **0.22:** structured exceptions, defaults, shared closures, and bytecode imports, delivered.
- **0.23:** VM-backed DAP, capability-safe VM embedding, host-function permissions, and VM diagnostics.
- **0.24:** semantic flow analysis, return checking, record validation, and cross-module contracts.
- **0.25:** FastAPI package, Pydantic conversion, and OpenAPI extension schemas.
- **0.26:** async functions, await, cancellation, and task groups.
- **0.27:** package resolver, lock files, signing, and private feeds.
- **0.28:** Java runtime service and Spring Boot starter.
- **0.29:** TypeScript SDK, React integration, and WebAssembly experiment.
- **1.0:** stable specification, PEAC policy, embedding ABI, and package format.
