# Roadmap

- **0.26:** native async syntax, VM suspension, awaitable hosts, cancellation, and deadlines, delivered.
- **0.27:** package resolver, pea.toml, lock files, checksums, signatures, and private feeds.
- **0.28:** Java runtime sidecar, Java SDK, Spring Boot starter, and typed transport contracts.
- **0.29:** TypeScript SDK, React hooks, UI schema renderer, and WebAssembly experiment.
- **0.30:** performance profiling, coverage, fuzzing, and production conformance hardening.
- **1.0:** stable specification, PEAC compatibility policy, embedding ABI, package format, and security review.
