# PeaLang Language-First Roadmap

## v0.1-v0.8 - completed foundation
Core interpreter, maintainability, automation, developer tooling, workflows, AI, projects and bounded agent/tool foundations.

## v0.9.0 - Language maturity I - completed
Exceptions/throw, default parameters and explicit execution-model guidance.

## v0.10.0 - Modules and namespaces
Planned: namespace-isolated imports, aliases, explicit exports and cleaner project dependency semantics.

## v0.11.0 - Optional typing
Planned: optional variable/parameter/return annotations and checker enforcement while retaining inference/dynamic use.

## v0.12.0 - Standard library maturity
Planned: documented stable contracts for strings, collections, math, random, file/path, JSON/CSV, date/time, regex and system facilities.

## v0.13.0 - Standalone runtime
Planned: package PeaLang so end users do not need Python knowledge; retain `pea` CLI and interpreter semantics.

## v0.14.0 - Cross-platform distribution
Planned: Windows/Linux/macOS distribution workflow and installation documentation.

## v0.15.0 - VS Code and LSP
Syntax highlighting, diagnostics, formatting, symbols and definition navigation.

## v0.16.0 - Debugger
Breakpoints, stepping, scopes and stack inspection.

## v0.17.0 - Package management
After namespaces and project semantics stabilise.

## v0.18.0 - Runtime performance
Profile-guided interpreter optimisation.

## v0.19.0 - Bytecode/VM prototype
Only after the language semantics stabilise.

## v1.0.0 - Stable PeaLang
Stable language specification, compatibility policy, runtime/toolchain and standard-library contracts.
