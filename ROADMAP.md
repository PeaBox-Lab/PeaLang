# Roadmap

- **0.28:** Java runtime sidecar, Java 17 SDK, health/readiness, compile/load/invoke APIs, and Spring Boot guidance, delivered.
- **0.29:** TypeScript SDK, React hooks, schema-driven UI extensions, registry transport/signatures, and browser/WASM feasibility layer.
- **0.30:** profiler, coverage, benchmarks, fuzzing, production conformance, observability, and security hardening.
- **0.31-0.34:** language specification completion, standard library stabilization, host ABI freeze, and cross-runtime conformance.
- **1.0:** stable grammar, type system, PEAC policy, embedding ABI, package signing, Java/Python integration contracts, and LTS compatibility policy.
