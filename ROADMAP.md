# Roadmap

- **0.23:** capability-safe VM embedding and VM-backed DAP, delivered.
- **0.24:** semantic flow analysis, record field validation, return checking, narrowing, and cross-module contracts.
- **0.25:** production FastAPI package, dependency injection, Pydantic conversion, middleware, and OpenAPI extension schemas.
- **0.26:** async functions, await, cancellation, task groups, and async host calls.
- **0.27:** package resolver, lock files, checksums, signing, and private feeds.
- **0.28:** Java runtime service, Java SDK, and Spring Boot starter.
- **0.29:** TypeScript SDK, React hooks, UI schema renderer, and WebAssembly experiment.
- **1.0:** stable specification, PEAC policy, embedding ABI, package format, and security review.
