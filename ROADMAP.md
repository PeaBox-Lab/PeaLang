# PeaLang Roadmap

## v0.1.0 - Core interpreter (completed)
Variables, expressions, control flow, functions, collections, files, REPL and CLI.

## v0.2.0 - Foundation and maintainability (completed)
Modular runtime, typed AST/source spans, diagnostics, interpolation, property access, loop control, indexed assignment, import foundation, formal grammar, tests and CI.

## v0.3.0 - Automation standard library
Planned: structured `file`, `path`, `json`, `csv`, `env`, `datetime`, `regex`, `http`, and guarded process modules.

## v0.4.0 - Developer experience
Planned: formatter, checker, richer test framework, documentation generator, improved REPL and editor syntax package.

## v0.5.0 - Workflows and concurrency
Planned only after the runtime safety and module contracts stabilize.

## v0.6.0+ - AI workflow identity
Planned: provider-neutral AI operations, structured extraction, tools and portable skills. Credentials must remain external.

## v1.0.0 - Stable platform
Stable language specification, compatibility policy, module system, standard-library contract and production hardening.
