# Roadmap

- **0.27:** package manifests, lock files, semver, local install, auditing, checksums, and reproducible packages, delivered.
- **0.28:** Java runtime sidecar, Java client SDK, Spring Boot starter, typed JSON transport, health endpoints, and script caching.
- **0.29:** TypeScript SDK, React hooks, UI schema renderer, package registry transport/signatures, and WebAssembly experiment.
- **0.30:** profiler, coverage, parser fuzzing, benchmarks, production conformance suite, and security hardening.
- **1.0:** stable language specification, PEAC compatibility policy, embedding ABI, package signing policy, and long-term compatibility guarantees.
