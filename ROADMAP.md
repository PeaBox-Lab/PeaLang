# Roadmap

- **0.32:** Ed25519 signing, public trust, revocation, verified HTTPS install, and offline cache, delivered.
- **0.33:** signed registry indexes, publisher identities, key rotation chains, registry authentication, package namespaces, and anti-replay metadata.
- **0.34:** WebAssembly VM prototype and cross-runtime conformance.
- **0.35:** normative language and standard-library specifications, stable host ABI, PEAC compatibility policy, and migration tooling.
- **1.0:** independent security review, production registry policy, stable specifications, cross-platform distribution, and LTS compatibility.
