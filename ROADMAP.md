# Roadmap

- **0.25:** FastAPI extension registry, routes, validation, OpenAPI metadata, and controlled errors, delivered.
- **0.26:** async functions, await, cancellation, task groups, async host functions, and FastAPI-native async extension execution.
- **0.27:** package resolver, pea.toml, lock files, checksums, signing, and private feeds.
- **0.28:** Java runtime sidecar, Java SDK, Spring Boot starter, and typed transport contracts.
- **0.29:** TypeScript SDK, React hooks, UI schema renderer, and WebAssembly experiment.
- **1.0:** stable specification, PEAC policy, embedding ABI, package format, security review, and production conformance suite.
