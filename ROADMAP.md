# PeaLang Roadmap

- **0.15:** Debug Adapter Protocol foundation, delivered.
- **0.16:** advanced debugging, frames, conditional breakpoints, and exception stops, delivered.
- **0.17:** built-in CLI and REPL help system, examples, topics, and usability improvements, delivered.
- **0.18:** resumable bytecode VM experiment and precise nested debug continuation.
- **0.19:** profiler, coverage, package workflow, and richer editor integration.
- **1.0:** grammar, standard library, CLI, and compatibility freeze.
