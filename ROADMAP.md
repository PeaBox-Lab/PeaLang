# Roadmap

- **0.33:** signed-registry metadata model, publisher namespaces, anti-replay state, immutable versions, and registry credentials, delivered.
- **0.34:** WebAssembly VM prototype, portable PEAC loader, browser execution sandbox, and cross-runtime differential conformance.
- **0.35:** normative grammar/language specification, standard-library specification, stable host ABI, PEAC compatibility rules, and migration tooling.
- **0.36:** optimizer, JIT/AOT feasibility, performance tuning, memory accounting, and long-running runtime hardening.
- **1.0:** independent security review, production package registry, stable specifications, cross-platform distribution, and LTS compatibility.
