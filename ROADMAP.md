# Roadmap

- **0.18:** embeddable Python runtime, delivered.
- **0.19:** optional type contracts, delivered.
- **0.20:** bytecode compiler and stack VM, delivered.
- **0.21:** VM control-flow parity, assignment opcodes, debug state, and VM embedding, delivered.
- **0.22:** structured exception tables, try/catch/finally, lexical closure cells, default arguments, and bytecode module imports.
- **0.23:** VM-backed DAP and unified capability-safe embedding.
- **0.24:** semantic flow analysis and cross-module typed contracts.
- **0.25:** dedicated FastAPI package and OpenAPI/Pydantic generation.
- **0.26:** async runtime and structured concurrency.
- **0.27:** package resolver, lock files, signing, and private feeds.
- **0.28:** Java service/client and Spring Boot starter.
- **0.29:** TypeScript SDK, React hooks, and WebAssembly experiment.
- **1.0:** stable specification, bytecode policy, embedding ABI, and package format.
