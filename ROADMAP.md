# Roadmap

- **0.18:** embeddable Python runtime and capability boundaries, delivered.
- **0.19:** optional type contracts and static diagnostics, delivered.
- **0.20:** bytecode format, compiler, stack VM, disassembler, and compiled artifacts, delivered.
- **0.21:** VM parity for exceptions, imports, closures, break/continue, compound assignment, async-ready suspension, and DAP integration.
- **0.22:** semantic flow analysis and cross-module contracts.
- **0.23:** dedicated FastAPI package and Pydantic/OpenAPI schema generation.
- **0.24:** async functions, await, cancellation, and structured concurrency.
- **0.25:** package lock files, resolver, signing, and private feeds.
- **0.26:** Java runtime service, client, and Spring Boot starter.
- **0.27:** TypeScript SDK, React hooks, schema renderer, and WebAssembly experiment.
- **1.0:** stable grammar, bytecode compatibility policy, embedding ABI, package format, and language specification.
