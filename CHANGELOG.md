# Changelog

## 0.21.0 - 2026-10-22
- Added VM support for break, continue, compound assignment, property/index assignment, and throw.
- Added RAISE, SET_PROPERTY, and SET_INDEX opcodes.
- Added VM breakpoints, stepping, continuation, stack inspection, locals, and source events.
- Added VMRuntime and VMModule for compiled extension embedding.
- Added interpreter-versus-VM parity tests.

## 0.20.0 - 2026-10-22
- Added PEAC bytecode format, compiler, stack VM, disassembler, compiled artifacts, and VM CLI commands.

## 0.19.0 - 2026-10-22
- Added optional types, records, unions, nullable types, generics, and type checking.

## 0.18.0 - 2026-10-22
- Added Python embedding, controlled host functions, capability checks, value conversion, and resource budgets.

## 0.17.0 - 2026-10-22
- Added built-in help foundations.

## 0.16.0 - 2026-10-22
- Added advanced debugger and DAP improvements.

## 0.15.0 - 2026-10-22
- Added the initial Debug Adapter Protocol server.

## 0.1.0 - 0.14.0
- Established language, automation, workflow, AI, editor, LSP, and debugger foundations.
