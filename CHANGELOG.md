# Changelog

## 0.23.0 - 2026-10-22
- Unified VM embedding with RuntimeOptions, permissions, and portable value conversion.
- Added capability-protected VM host functions and modules.
- Added VM execution time and instruction budgets.
- Added the VM-backed DAP server and `pea vm-dap`.
- Added VM DAP lifecycle, breakpoint, stack, scope, variable, output, evaluation, and exception-info support.
- Added VM security and DAP regression tests.

## 0.22.0 - 2026-10-22
- Added structured VM exceptions, defaults, shared closures, imports, and module caching.

## 0.21.0 - 2026-10-22

## 0.20.0 - 2026-10-22

## 0.1.0 - 0.17.0
