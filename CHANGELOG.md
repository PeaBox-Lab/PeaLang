# Changelog

## 0.17.0 - 2026-10-22
- Added `pea help` and topic-based command-line help.
- Added friendly `help`, `help TOPIC`, and `? TOPIC` REPL aliases.
- Added `:topics`, `:commands`, `:examples`, and `:version` commands.
- Added structured help topics and partial-match suggestions.
- Added REPL guidance distinguishing PeaLang from operating-system commands.
- Added dedicated help documentation and automated regression tests.

## 0.17.0 - 2026-10-22
- Added captured function call-stack frames and per-frame local scopes.
- Added conditional breakpoints, hit-count conditions, and log points.
- Added exception breakpoint support for uncaught PeaLang errors.
- Added source-aware breakpoint lookup for imported-module paths.
- Added DAP `initialized`, `stopped`, `output`, and `terminated` events.
- Added dynamic scope references and frame-aware expression evaluation.
- Added debugger and DAP regression tests.
- Expanded foundations, debugging, release, help, and user documentation.

## 0.15.0 - 2026-10-22
- Added stdio Debug Adapter Protocol server through `pea dap`.
- Added interpreter statement hooks for nested block visibility.
- Added step-in, step-over, step-out, scopes, variables, evaluate and breakpoint hit tracking.
- Added DAP regression tests and VS Code debugger configuration sample.
