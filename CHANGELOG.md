# Changelog

## 0.22.0 - 2026-10-22
- Added structured VM exception handlers for try/catch/finally/throw.
- Added frame unwinding and stack restoration for handled exceptions.
- Added literal default parameters to PEAC code objects.
- Added shared lexical closure environments.
- Added compiled module imports, export namespaces, relative resolution, and module caching.
- Added nine new VM conformance tests.

## 0.21.0 - 2026-10-22
- Added VM loop-control parity, assignment opcodes, debug state, and VM-backed embedding.

## 0.20.0 - 2026-10-22
- Added PEAC bytecode, compiler, stack VM, disassembler, and compiled artifacts.

## 0.19.0 - 2026-10-22
- Added optional types and static diagnostics.

## 0.18.0 - 2026-10-22
- Added Python embedding and capability boundaries.

## 0.1.0 - 0.17.0
- Established the language, automation, AI, editor, debugger, DAP, and help foundations.
