# PeaLang Type System 0.36

Version 0.36 completes the next foundational type layer with generic function contracts and substitution, generic inference helpers, structural protocols, cross-module project contract collection, and explicit `Result<T,E>`, `Option<T>`, and `Future<T>` constructors. Untyped PeaLang remains valid.

Commands: `pea typecheck`, `pea semantic`, `pea typecheck-project .`.
