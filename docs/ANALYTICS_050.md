


# Data Analytics and Statistics 0.50

Dependency-light descriptive analytics over PeaLang DataFrames: describe, mean, median, mode, quantiles, sample/population variance and standard deviation, covariance/correlation, frequency tables, crosstabs, dense ranking, cumulative calculations, rolling statistics, IQR outlier detection, missing-data/duplicate profiling and correlation matrices. Statistical functions ignore nulls. Sample variance is the default.
