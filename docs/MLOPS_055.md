# ML Deployment, Monitoring and Governance 0.55

Adds integrity-checked model bundles, batch inference, prediction audit records, PSI/categorical/prediction drift, group fairness summaries, threshold optimization, Platt calibration, a persistent model registry with lifecycle states and rollback metadata, training-serving schema compatibility, inference benchmarks and an optional FastAPI adapter. Fairness metrics are diagnostic and require legal, ethical and domain review before decisions.
