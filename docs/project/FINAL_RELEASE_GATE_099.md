# PeaLang 0.99 Final 1.0 Release Gate

v0.99 is the final pre-1.0 gate. Feature development remains frozen.

## Required for GO-1.0
- Verified v0.98 rehearsal evidence.
- No unresolved critical/high blocker or unbounded waiver.
- Reviewed README, user guide, basics, API reference, upgrade guide, support/security policies, release notes and cumulative changelog.
- Final 1.0.0 wheel, sdist and container with SHA-256, verified signature, provenance and SBOM.
- Passing security, compatibility and operations evidence.
- Release, security and operations owner approvals.

This module validates supplied evidence. It does not assert that external reviews, signatures, CI matrices or approvals occurred. Missing required real evidence is always NO-GO.
