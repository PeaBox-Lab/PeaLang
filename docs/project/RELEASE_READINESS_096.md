
# PeaLang 0.96 Release Readiness Closure

The 1.0 feature freeze remains active. v0.96 consolidates evidence rather than adding a feature family.

## Mandatory closure
- Verified v0.95, security, license, cross-platform, reproducibility and operations evidence.
- User guide, basics, API docs, upgrade guide, support policy and release notes.
- Wheel, sdist, container, offline-install, rollback, backup/restore and monitoring readiness.
- Residual-risk register with no critical/high unresolved risk.
- Release, security and operations owner approvals.

The gate remains NO-GO when real evidence or approvals are absent.
