# PeaLang 0.89 Release-Candidate Hardening

## Scope freeze
0.89 introduces no new feature family. Its purpose is to aggregate and enforce evidence produced by the stabilization work from 0.76 through 0.88.

## Mandatory GO gates
- Complete regression suite passes.
- Public API compatibility gate passes.
- Security/adversarial gates pass.
- Performance regression budgets pass.
- Supply-chain and package verification pass.
- Migration/upgrade fixtures pass.
- Developer tooling certification passes.
- Release documentation is complete.
- Windows, Linux and macOS evidence is present.
- No unresolved blocker/high-severity defect exists without an explicit registered waiver.

Any missing mandatory evidence produces NO-GO. Waivers must name scope, owner, reason and expiry version.
