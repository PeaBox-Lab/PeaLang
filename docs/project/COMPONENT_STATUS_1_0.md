
# PeaLang 1.0 Component Status

| Component | Status | Compatibility commitment |
|---|---|---|
| Language syntax, interpreter, PEAC, VM | Stable | Semantic versioning |
| Python embedding and FastAPI | Stable | Semantic versioning |
| Type system, stdlib, package/security model | Stable | Semantic versioning |
| Java and TypeScript clients | Supported | Compatible client contract |
| DataFrame, SQL core, analytics | Supported | Stable documented surface |
| ML, agents, distributed compute/serving | Preview | May evolve with migration notes |
| Browser/WASM native execution | Preview | Not part of stable 1.0 surface |
| Governed natural-language planner | Experimental | No compatibility promise |
