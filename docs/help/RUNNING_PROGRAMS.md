# Running PeaLang Programs
- Single file: `pea app.pea`
- Explicit form: `pea run app.pea`
- Interactive: `pea repl`
- Project: `pea start`
- Version: `pea --version`

PeaLang v0.9 is interpreter-based. Compilation is not required. If `pea` is not found after development installation, run `python -m pealang app.pea` from an environment where PeaLang is installed.
