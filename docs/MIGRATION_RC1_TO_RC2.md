# Migration from 0.63 RC1 to RC2

1. Back up registries and monitoring stores.
2. Verify RC1 artifacts and capture the RC1 API snapshot.
3. Install RC2 in an isolated environment.
4. Compare RC1 and RC2 public API snapshots.
5. Run serving, connector, package and language smoke tests.
6. Validate rollback to RC1.

No destructive schema migration is introduced.
