# Cloud Connectors 0.46

Adds OData and SFTP. OData supports $select, $filter, $expand, $orderby, $top, $skip, $count, $search, custom options, @odata.nextLink pagination, metadata and DataFrame conversion. SFTP supports strict host-key verification by default, password/key authentication, listing, read/write, upload/download, rename/remove, and CSV/JSON DataFrame reads. SFTP uses optional `paramiko`. Never enable unknown-host acceptance in production.
