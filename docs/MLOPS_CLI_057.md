


# Pipeline Portability and MLOps CLI 0.57

Adds versioned ProductionPipeline serialization for StandardScaler/MinMaxScaler plus linear, ridge, lasso and logistic models; a SQLite monitoring backend; JSON alert policy loading; deployment manifests; and `pea-ml` commands for bundle, verify, register, promote, monitor and alerts. Unsupported transformer types fail closed instead of being silently dropped.
