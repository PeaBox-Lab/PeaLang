# PeaLang Data Foundation 0.42

0.42 introduces `DataType`, `Field`, `Schema`, `DataFrame`, `LazyFrame`, a connector registry, schema inference, CSV/JSON/JSONL import/export and core select/filter/with_column/drop/rename/sort/limit/distinct operations. The dependency-light core is intentional. Excel, Parquet, Arrow, databases, SQL, branded connectors, statistics, unstructured data and streaming follow in later releases.
