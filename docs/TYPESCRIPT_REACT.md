# TypeScript and React Integration

PeaLang 5.25.0 ships a TypeScript client and React integration for the
runtime sidecar.

## TypeScript

`@pealang/client` provides `PeaLangClient`, portable `PeaValue` types,
compile/load/invoke calls with array arguments, and health/readiness probes.

## React

`@pealang/react` provides `PeaLangProvider`, `usePeaLang`, `usePeaFunction`,
and `PeaUi`. See `docs/REACT_SDK.md` for details.

Version: 5.25.0.
