



# Secure MLOps and Monitoring Operations 0.56

Adds optional Ed25519 bundle signatures and Fernet artifact encryption through `cryptography`, a persistent monitoring event store, time-filtered summaries, threshold alerts, acknowledgement workflow, promotion policies, deterministic canary routing, champion/challenger comparisons, rollback conditions and structured inference logs. Encryption keys and signing keys must be held in a runtime secret provider, not included in bundles.
