


# User Guide

Use `pea run`, `pea repl`, `pea fmt`, `pea check`, `pea test`, `pea docs`, `pea debug`, and `pea dap`. Keep process execution disabled for untrusted code.

## Standard library 0.35
Prefer `std.*`, for example `std.string.upper("Pea")`. Filesystem, HTTP, logging and concurrency operations require explicit permissions in embedded runtimes.
