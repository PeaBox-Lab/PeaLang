# User Guide v0.3.0
Use `let` and `const` for bindings, functions for reuse, dictionaries/lists for structured data, and interpolation for readable output. Split programs with local imports. For automation, prefer namespaced APIs such as `json.read`, `csv.write`, `file.read`, and `path.join`. Keep secrets outside source and retrieve them with `env.require`. Treat network data as untrusted. Enable `process.run` only for reviewed programs and pass arguments as a list.
