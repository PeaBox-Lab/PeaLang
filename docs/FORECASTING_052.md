
# Forecasting and Accelerated Analytics 0.52

Adds chronological train/test splitting, MAE/MSE/RMSE/MAPE evaluation, linear-trend forecasting with residual confidence bands, recursive moving-average forecasting, simple exponential smoothing, additive seasonal decomposition, grouped forecasts, chart-ready output, optional NumPy acceleration and forecast benchmarks. These are transparent baseline methods, not substitutes for validated domain models.
