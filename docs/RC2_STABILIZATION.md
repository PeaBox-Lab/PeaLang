# PeaLang 0.63 RC2 Stabilization

RC2 is a defect-correction and evidence release. No broad feature scope is added. It refreshes the public API snapshot, checks RC1-to-RC2 compatibility, preserves upgrade mappings, records automated validation evidence and keeps all external GA gates explicit.

## RC2 rules
- No public API removal or signature change from RC1.
- Defect corrections must retain backwards compatibility.
- External integration, license, security and soak gates remain release blockers until evidenced.
