

# PeaLang 0.82.0 Alpha 1 Release Notes

## Theme
Packaging, reproducibility and software supply-chain hardening.

## Added
- Deterministic source manifests and tamper checks.
- CycloneDX SBOM verification.
- SLSA/in-toto provenance verification.
- Ed25519 detached signing and signature verification.
- Dependency lock evidence and offline-install checks.
- Aggregated packaging quality gates.

## Compatibility
Additive to 0.81 migration compatibility, 0.80 observability and earlier runtime APIs. Package version: `0.82.0a1`.
