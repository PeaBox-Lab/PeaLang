


# PeaLang 0.81.0 Alpha 1 Release Notes

## Theme
Compatibility and migration hardening for the v1 stabilization line.

## Added
- Deprecation lifecycle ledger and release validation.
- Ordered, resumable and reversible schema/config migrations.
- Migration integrity events with before/after SHA-256 hashes.
- Public API snapshot and diff enforcement.
- Breaking-change approval gates and upgrade fixtures.

## Compatibility
The release is additive and retains the 0.80 observability and 0.79 integration-hardening APIs. Package version: `0.81.0a1`.
