

# PeaLang 0.85.0 Alpha 1 Release Notes

## Theme
Data and connector conformance for the v1 stabilization line.

## Added
- Connector capability declarations and certification suites.
- SQL dialect, parameter binding, transaction and rollback contracts.
- Streaming recovery, replay, checkpoint and deduplication semantics.
- Object-storage pagination, range-read and multipart-failure fixtures.
- Certification reports, digests and release gates.

## Compatibility
Additive to 0.84 concurrency, 0.83 performance and earlier connector APIs. Package version: `0.85.0a1`.
