
# PeaLang 0.90.0 RC1 Release Notes

## Theme
API freeze for the PeaLang 1.0 release line.

## Added
- Canonical public API freeze manifests and SHA-256 digests.
- Additive versus breaking-change classification.
- Approval-required gates for changed and removed frozen surfaces.
- Frozen syntax, runtime, package, diagnostic and versioned-bytecode policy signals.
- Machine-readable 1.0 compatibility contract.

## Development policy
No normal feature-family development should cross the 0.90 freeze. Versions 0.91-0.96 are release-candidate validation lines focused on compatibility, upgrades, security, performance and ecosystem soak.
