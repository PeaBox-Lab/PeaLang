


# PeaLang 0.71.0 Release Notes

PeaLang 0.71 merges three roadmap targets into one cohesive release: dataset and column lineage, operational observability with SLA/alert/audit support, and declarative dashboards with React code generation.

## Compatibility
The 0.69 DAG and 0.70 durable orchestration APIs remain available. The new modules are additive.
