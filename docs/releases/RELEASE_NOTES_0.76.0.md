# PeaLang 0.76.0 Release Notes

PeaLang 0.76 begins the formal v1 hardening line. It adds adversarial policy probes, public API compatibility detection and a unified machine-checkable release gate spanning tests, security probes, public API removals and file retention.

## Repository structure
The root is intentionally cleaner. Versioned release notes are stored under `docs/releases/`, retention evidence under `docs/retention/`, handovers under `docs/handover/`, and project governance/history under `docs/project/`. The detailed root README and single cumulative root CHANGELOG remain the primary entry points.
