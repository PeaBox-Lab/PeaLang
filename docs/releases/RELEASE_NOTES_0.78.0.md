


# PeaLang 0.78.0 Release Notes

PeaLang 0.78 advances the v1 stabilization line from performance hardening into trust-boundary security hardening. It adds bounded host-input validation, filesystem allow-root checks, URL scheme/private-address policy, recursive credential redaction and tamper-evident SHA-256/HMAC audit chains. Existing language, data, ML, orchestration, agent and embedding capabilities are retained.
