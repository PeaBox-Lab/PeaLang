# PeaLang 0.80.0 Alpha 1 Release Notes

## Theme
Observability and operations hardening for the v1 stabilization line.

## Added
- W3C trace-context propagation helpers and parent/child span recording.
- Bounded span export and stable metric conventions with cardinality protection.
- Explicit liveness/readiness contracts.
- Redacted, bounded diagnostic bundles with SHA-256 manifests.
- Regression tests and operations guidance.

## Compatibility
This is additive. Existing 0.79 enterprise integration APIs remain available. Package version: `0.80.0a1`.
