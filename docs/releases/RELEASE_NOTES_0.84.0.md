


# PeaLang 0.84.0 Alpha 1 Release Notes

## Theme
Concurrency and resilience hardening for the v1 stabilization line.

## Added
- Cancellation and deadline propagation.
- Fail-fast structured task groups.
- Retry-safety and idempotency controls.
- Graceful shutdown and task draining.
- Concurrency/resilience release gates and regression tests.

## Compatibility
Additive to 0.83 performance, 0.82 supply-chain and earlier APIs. Package version: `0.84.0a1`.
