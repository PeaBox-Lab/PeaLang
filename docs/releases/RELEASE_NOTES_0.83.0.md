
# PeaLang 0.83.0 Alpha 1 Release Notes

## Theme
Runtime Performance II for the v1 stabilization line.

## Added
- Representative benchmark suite runner.
- Mean/p50/p95/p99 latency, throughput and peak-memory measurements.
- Versioned performance baselines and regression gates.
- Hot-path profiling for compiler/runtime operations.
- Cache hit/miss/load/eviction instrumentation.
- Memory-pressure and retained-growth probes.

## Compatibility
This release extends the v0.77 performance APIs and retains v0.82 supply-chain, v0.81 compatibility and v0.80 observability APIs. Package version: `0.83.0a1`.
