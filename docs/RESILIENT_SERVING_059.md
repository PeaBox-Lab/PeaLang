

# Secure and Resilient Serving 0.59

Adds per-client sliding-window rate limits, bounded concurrency, request timeouts, environment configuration, JSON service logs, correlation IDs, trace hooks, health degradation, graceful model reload, runtime deployment-plan switching, critical-alert rollback, signed-pipeline verification hooks, encrypted pipeline loading and audit-retention pruning. Signing and encryption use the optional `cryptography` dependency.
