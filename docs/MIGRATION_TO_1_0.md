



# PeaLang 1.0 Migration Readiness Report

0.41 prepares migration evidence but does not declare 1.0 readiness. Preserve 0.x source compatibility where possible. Before 1.0, decide Stable/Preview status for optional typing, PEAC, async, packages and WASM; publish the bytecode compatibility promise; resolve deprecations; obtain required CI/coverage evidence; validate real pilots; and complete security review.

Recommended migration command remains `pea migrate --from <version> --to <version> . --check` before writing changes.
