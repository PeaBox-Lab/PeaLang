# Overview

PeaLang libraries are self-contained packages that can be shared and reused across projects. A library consists of PeaLang source files that export functions, types, and other symbols for use by other PeaLang programs.

## Library Format

PeaLang libraries are distributed as `.pelib` files - tar.gz archives containing:
- Source code (`.pea` files)
- Compiled bytecode (`.peac` files)
- Manifest (`manifest.json`) with metadata
- Export manifest (`exports.json`) with exported symbols
- README and documentation

---

# Library Structure

A PeaLang library project follows this structure:

```
mylib/
├── pea.toml              # Library manifest
├── src/
│   └── mylib.pea         # Library source code
├── tests/
│   └── test_mylib.pea    # Test suite
├── README.md             # Documentation
└── LICENSE               # License file
```

## pea.toml Manifest

The `pea.toml` file defines your library's metadata:

```toml
[project]
name = "mylib"
version = "1.0.0"
description = "A useful PeaLang library"
entry = "src/mylib.pea"

[library]
exports = ["add", "greet", "version"]

[dependencies]
# List dependencies here
# another-lib = { version = "1.0.0" }

[permissions]
allow = []
```

### Manifest Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Library name (lowercase, hyphen-separated) |
| `version` | string | Yes | Semantic version (e.g., "1.0.0") |
| `description` | string | No | Human-readable description |
| `entry` | string | Yes | Entry point file (relative to project root) |
| `exports` | string[] | No | List of exported symbol names |
| `dependencies` | table | No | Dependencies on other libraries |
| `permissions` | table | No | Required permissions |

# Creating a Library

## Step 1: Scaffold a New Library

```bash
pea init --template library mylib
cd mylib
```

This creates:
```
mylib/
├── pea.toml
├── src/mylib.pea
├── tests/test_mylib.pea
├── README.md
└── LICENSE
```

## Step 2: Write Library Code

Edit `src/mylib.pea`:

```pea
// mylib - A utility library for common operations
// Generated by pea init --template library

export function add(a, b) {
    return a + b
}

export function subtract(a, b) {
    return a - b
}

export function multiply(a, b) {
    return a * b
}

export function divide(a, b) {
    if b == 0 {
        throw "Division by zero"
    }
    return a / b
}

export function version() {
    return "1.0.0"
}
```

### Exporting Functions

Use the `export` keyword to make functions available to consumers:

```pea
export function my_function(arg1, arg2) {
    // Function body
    return result
}
```

Only exported functions are accessible to consumers of your library.

# Writing Tests

Tests ensure your library works correctly. Create `tests/test_mylib.pea`:

```pea
// Tests for mylib
import "../src/mylib.pea" as mylib

test "add function" {
    expect mylib.add(2, 3) == 5
    expect mylib.add(-1, 1) == 0
    expect mylib.add(0, 0) == 0
}

test "subtract function" {
    expect mylib.subtract(10, 3) == 7
    expect mylib.subtract(5, 5) == 0
}

test "multiply function" {
    expect mylib.multiply(3, 4) == 12
    expect mylib.multiply(-1, 5) == -5
}

test "divide function" {
    expect mylib.divide(10, 2) == 5
    expect mylib.divide(7, 2) == 3
}

test "version function" {
    expect mylib.version() == "1.0.0"
}
```

Run tests with:

```bash
pea test
```

# Building and Publishing

## Building a Library Package

```bash
pea build --library
```

This creates `mylib-1.0.0.pelib` - a tar.gz archive containing:
- `src/mylib.pea` - Source code
- `src/mylib.peac` - Compiled bytecode
- `pom.xml` - Manifest
- `README.md` - Documentation
- `LICENSE` - License

## Publishing to a Registry

```bash
pea publish ./mylib --registry http://registry.example.com --token <token>
```

Or with the shorthand if you have logged in:

```bash
pea login --registry http://registry.example.com --token <token>
pea publish ./mylib
```

## Consuming a Library

In your project's `pea.toml`:

```toml
[dependencies]
mylib = { registry = "http://registry.example.com", version = "1.0.0" }
```

Or use a Git repository:

```toml
[dependencies]
mylib = { git = "https://github.com/you/mylib.git", version = "1.0.0" }
```

Or use a local path:

```toml
[dependencies]
mylib = { path = "./path/to/mylib" }
```

Then import and use in your code:

```pea
import "mylib" as mylib

print mylib.add(2, 3)  // Output: 5
print mylib.greet("World")  // Output: Hello, World
```

# Best Practices

## Library Design

1. **Keep functions pure** - Functions should be deterministic and have no side effects
2. **Use descriptive names** - Function names should clearly indicate what they do
3. **Document your API** - Add comments explaining what each function does
4. **Handle errors gracefully** - Use throw for error conditions
5. **Validate inputs** - Check input types and ranges
6. **Keep functions small** - Each function should do one thing well

## Versioning

Follow semantic versioning (semver):
- **MAJOR** version when you make incompatible API changes
- **MINOR** version when you add functionality in a backward-compatible manner
- **PATCH** version when you make backward-compatible bug fixes

Example version progression:
```
1.0.0 -> 1.0.1 (bug fix)
1.0.1 -> 1.1.0 (new feature, backward compatible)
1.1.0 -> 2.0.0 (breaking change)
```

## Documentation

Include a `README.md` with:
- Installation instructions
- Usage examples
- API reference
- License information
- Contact information

Example README:

```markdown
# mylib

A useful PeaLang library for common operations.

## Installation

Add to your `pea.toml`:

```toml
[dependencies]
mylib = { version = "1.0.0" }
```

## Usage

```pea
import "mylib" as mylib

print mylib.add(2, 3)  // Output: 5
print mylib.greet("World")  // Output: Hello, World
```

## API

### add(a, b)
Returns the sum of two numbers.

### greet(name)
Returns a greeting string.

### version()
Returns the library version.

## License

MIT
```

# Example Library

Here's a complete example of a utility library:

## `pealang-math-utils`

**`pea.toml`:**
```toml
[project]
name = "math-utils"
version = "1.0.0"
description = "Mathematical utility functions"
entry = "src/math-utils.pea"

[library]
exports = ["add", "subtract", "multiply", "divide", "power", "sqrt", "factorial"]

[dependencies]

[permissions]
allow = []
```

**`src/math-utils.pea`:**
```pea
// math-utils - Mathematical utility functions

export function add(a, b) {
    return a + b
}

export function subtract(a, b) {
    return a - b
}

export function multiply(a, b) {
    return a * b
}

export function divide(a, b) {
    if b == 0 {
        throw "Division by zero"
    }
    return a / b
}

export function power(base, exponent) {
    return base ^ exponent
}

export function sqrt(x) {
    if x < 0 {
        throw "Cannot compute square root of negative number"
    }
    // Simple implementation
    return x ^ 0.5
}

export function factorial(n) {
    if n < 0 {
        throw "Factorial not defined for negative numbers"
    }
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

export function version() {
    return "1.0.0"
}
```

**`tests/test_math-utils.pea`:**
```pea
import "../src/math-utils.pea" as math

test "add function" {
    expect math.add(2, 3) == 5
    expect math.add(-1, 1) == 0
}

test "subtract function" {
    expect math.subtract(10, 3) == 7
    expect math.subtract(5, 5) == 0
}

test "multiply function" {
    expect math.multiply(3, 4) == 12
    expect math.multiply(-1, 5) == -5
}

test "divide function" {
    expect math.divide(10, 2) == 5
    expect math.divide(7, 2) == 3
}

test "power function" {
    expect math.power(2, 3) == 8
    expect math.power(5, 0) == 1
}

test "factorial function" {
    expect math.factorial(0) == 1
    expect math.factorial(5) == 120
}

test "version function" {
    expect math.version() == "1.0.0"
}
```

# Publishing and Consuming

## Publishing Workflow

1. Develop your library
2. Test thoroughly with `pea test`
3. Build with `pea build --library`
4. Publish with `pea publish ./mylib --registry <registry-url> --token <token>`
5. Tag the release in Git: `git tag v1.0.0 && git push origin v1.0.0`

## Consuming Libraries

Add to your `pea.toml`:

```toml
[dependencies]
math-utils = { version = "1.0.0" }
```

Import and use:

```pea
import "math-utils" as math

print math.add(5, 3)   // Output: 8
print math.factorial(5) // Output: 120
```

# Advanced Topics

## Dependency Management

Specify dependencies in `pea.toml`:

```toml
[dependencies]
another-lib = { version = "1.0.0" }
another-lib2 = { version = ">=2.0.0, <3.0.0" }
```

## Permissions

Declare required permissions:

```toml
[permissions]
allow = ["file.read", "file.write", "http.request"]
```

Available permissions:
- `file.read` - Read files
- `file.write` - Write files
- `http.request` - Make HTTP requests
- `concurrent` - Use concurrency
- `log` - Write to logs

## Environment Variables

Access environment variables:

```pea
import std.env

let api_key = std.env.get("API_KEY", "default-key")
```

# Troubleshooting

## Common Issues

### "Library not found"
- Check the library name in `pea.toml`
- Verify the registry URL is correct
- Check your authentication token

### "Permission denied"
- Add required permissions to `pea.toml`
- Check file system permissions

### "Import failed"
- Check the import path
- Verify the library is installed
- Check for syntax errors in the library
